# AxiGrid

Optimization Intelligence for Complex Decisions.

## Stack

- Next.js 15 (App Router)
- React 19 + TypeScript
- Tailwind CSS
- Framer Motion
- Lucide React

## Run Locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Deploy

Push to GitHub and connect to Netlify — `netlify.toml` is pre-configured.
